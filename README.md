# PAM Desktop

Web-App zur Auftrags- und Objektverwaltung für einen Handwerks- und
Sachverständigenbetrieb. Läuft im Browser, ohne Installation und ohne Server.

Die App speichert keine Daten in diesem Projekt. Alle Inhalte liegen im
Google-Drive-Konto der anmeldenden Person und werden erst nach deren Anmeldung
geladen — ohne Anmeldung startet die App leer.

Gegenstück fürs Handy: PAM Mobil.
